# Evidence

## Sample Email Analysis

The following evidence represents a fictional phishing email created for educational practice.

### Indicators Observed

1. Urgent language
2. Suspicious sender format
3. Request for account verification
4. Need to verify links before clicking

### Result

The sample was identified as suspicious based on multiple phishing indicators.

### Safety

This is a fictional educational example. No real email, account, person, or organization was targeted.

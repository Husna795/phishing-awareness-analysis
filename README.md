# Phishing Awareness & Email Analysis

## Objective

This project focuses on learning how to identify common phishing indicators using a safe sample email.

## Indicators Analyzed

- Suspicious sender
- Urgent or threatening language
- Suspicious links
- Unexpected attachments
- Requests for personal information
- Spelling and grammar issues
- Impersonation

## Tools Used

- Browser
- Email analysis
- GitHub

## Safety Note

This is an educational project using a safe sample.
No real person, account, or organization was targeted.

## What I Learned

I learned how to recognize common warning signs that can indicate a phishing attempt and how to document security observations safely.
